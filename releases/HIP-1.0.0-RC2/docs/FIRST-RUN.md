# HIP First Run

## After Adding HIP
1. Open Settings -> Devices & Services -> HIP.
2. Confirm these values are visible:
   - HIP Version
   - Kernel Version
   - Installed Modules
   - Runtime Status
3. Press:
   - Validate Installation
   - Run Smoke Tests
4. Review the Update entity for installed and repository versions.
5. Export a support bundle to confirm diagnostics work.

## Expected Module List
- Kernel
- Security
- Media
- Notifications
- Snapshots
- Visitor Intelligence
- Dashboard
- Metrics
- Future AI

## Expected Outcome
The integration loads, reports healthy runtime status, and exposes actionable management controls without changing package execution behavior.
