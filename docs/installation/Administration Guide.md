# Administration Guide

## Overview
The HIP integration is the management layer for HIP. It does not replace the Kernel or package modules.

## Settings -> Devices & Services
Use the HIP integration page to review:
- HIP Version
- Kernel Version
- Installed Modules
- Runtime Status

## Actions
Use the integration buttons or services to:
- Validate Installation
- Reload HIP
- Run Smoke Tests
- Export Support Bundle
- Open Documentation

## Diagnostics
Use diagnostics download or `hip.export_support_bundle` to collect:
- Kernel Version
- Module Versions
- Configuration
- Device Registry
- Event Statistics
- Recent Errors
- Runtime Metrics
