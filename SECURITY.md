# Security Policy

## Reporting
Report suspected security issues privately through GitHub Security Advisories or by contacting the repository owner directly.

## Scope
Security issues include:
- Unauthorized access paths
- Exposure of secrets or tokens
- Unsafe automation behavior with security impact
- Dependency or workflow misconfiguration that weakens repository integrity

## Response Expectations
- Acknowledge receipt as soon as practical.
- Assess severity and production impact.
- Prepare mitigation, migration, and rollback guidance before broad disclosure when possible.

## Handling
Do not open public issues for active vulnerabilities until the owner confirms disclosure is safe.
